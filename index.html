03 / DAY BY DAY

逐日详细攻略

这是带缓冲的建议时间表，景点、机场、火车交通以现场导航为准。最重要的安排加深色突出，不值得为了补打卡把自己赶累。

11/28 周六成都 · 到达日
主题：太古里夜行。第一天轻松散步，不追求跑满景点。
已订酒店·2晚商圈步行4–6km
  1. 11:45—16:05
    杭州萧山 → 成都天府
    经停航班，具体经停流程、航站楼、行李额度以飞猪出票信息为准。
  2. 16:05—18:30
    出机场 → 春熙路如家
    下机、出机场、乘车入城；18:30是估计时间，航班延误则顺延。
  3. 19:00—21:30
    春熙路 → IFS 熊猫 → 太古里 → 大慈寺外围 → 望平街
    晚饭随意解决，目标步行4–6公里左右；商圈热闹，别为了刷步数走偏僻路。
  4. 22:00 左右
    回酒店休息
    若当天比较累，望平街可直接省略。
📍 现场提醒与备选

大慈寺当晚如果已经关闭，就只看外围街区；别把第一天排成打卡冲刺。

第二天睡到10点左右即可，保留体力参观历史文化景点。

11/29 周日成都 · 历史文化
主题：武侯祠、杜甫草堂、四川博物院，晚上约同学吃火锅。
上午偏松弛博物馆16:00前入场晚上火锅
  1. 10:00—11:10
    起床、早餐，出发去武侯祠
    不赶9点开馆，按实际酒店位置选择地铁或打车。
  2. 11:15—12:35
    武侯祠：汉昭烈庙、诸葛亮殿、惠陵、红墙
    保留约80分钟，锦里如顺路可短暂经过。
  3. 12:35—13:10
    午饭：KFC / 麦当劳 / 简餐
    简单吃、尽快补充体力；不专门找排队名店。
  4. 13:10—13:45
    武侯祠 → 杜甫草堂
    公交或打车，实际按导航实时路况。
  5. 13:45—15:00
    杜甫草堂：诗史堂、花径、茅屋、工部祠
    历史建筑与庭院结合，逛累了可以慢慢走。
  6. 15:00—15:20
    步行前往四川博物院
    杜甫草堂北门方向到四川博物院很近；注意选正确出口与入口。
  7. 15:20—16:50
    四川博物院：永乐宫特展优先
    先看山西芮城永乐宫建筑壁画与迁建；有剩余时间再看汉代陶石。务必16:00前入馆。
  8. 17:00—18:30
    自由安排 / 川大望江校门拍照
    拍校门只需10–15分钟。需见同学就由同学所在地决定。
  9. 18:30 后
    成都火锅＋与同学见面
    优先提前约好位置；夜间以聊天、休息为主。
📍 现场提醒与备选

四川博物院常规17:00闭馆、16:00停止入馆，下午时间是这一日的硬边界。若前面拖延，锦里直接跳过、草堂略缩短。

永乐宫特展单独购票。四川博物院免费基础参观仍需实名预约。

成都博物馆不要硬塞；即使提前看完，也可以直接去人民公园或休息。

11/30 周一成都 → 重庆
主题：人民公园慢生活；傍晚到重庆，晚上完成洪崖洞正面夜景＋朝天门。
16:28 重庆北到站主目标：江北岸洪崖洞夜景朝天门同晚完成
  1. 09:30—10:10
    起床、收拾行李
    酒店退房前确认必带物品。
  2. 10:15—11:20
    成都人民公园＋保路运动纪念碑＋盖碗茶
    灵活安排：天气不好或起晚了，缩短或取消。
  3. 11:20—12:10
    回酒店、退房、取箱子、简单午饭
    不要为了喝茶耽误中午去车站。
  4. 12:15—13:25
    前往成都东站
    目标提前约1小时到站，按导航计算更准确。
  5. 14:28—16:28
    成都东 → 重庆北
    12306已订。
  6. 16:40—18:00
    重庆北站 → 解放碑如家·neo
    建议坐轨道交通；箱子走电梯通道，重庆街面高差大，切忌只看地图直线距离。
  7. 18:05—18:50
    酒店 → 大剧院站 → 江北岸观景点
    小什字附近可乘6号线至大剧院站；施工期间以现场开放出口和步道为准。
  8. 18:50—19:40
    江北岸正面拍洪崖洞、千厮门大桥
    本次重庆旅行绝对最高优先级。灯光、江面反射、两岸城市层次。
  9. 19:40—20:20
    按可通行路线登上千厮门大桥，步行回渝中
    在桥上补一组洪崖洞俯视照；若桥头通道绕远或封闭，改地铁过江。
  10. 20:20—20:50
    洪崖洞建筑外观近拍
    侧重外立面，景区内部可跳过，避免排队。
  11. 20:50—21:40
    朝天门、来福士、两江交汇
    主要看地理与城市夜景。若步行路线因施工绕行，直接地图导航正常道路。
  12. 21:40 以后
    解放碑逛逛、夜宵、回酒店
    体力不足可直接回酒店，朝天门也可挪到次日上午。
📍 现场提醒与备选

11月30日晚洪崖洞预计18:30亮灯；具体以当日公告为准。务必先确保江北岸主机位，不需要卡死每站的分钟数。

大剧院下方江滩曾有施工或部分路段封闭：只走正规开放的观景平台和步道，不去临水无护栏碎石滩。

重庆街面落差很大，酒店到地铁、桥面到江边都不要简单按“直线500米”估算体力。

12/01 周二重庆 → 武汉
主题：上午缓慢退房和吃饭，下午飞武汉，晚上同学带逛。
15:25 起飞武汉同学带逛

  2. 10:45—11:45

    火锅务必确认11点左右营业、不排长队；一旦时间不够就改小面。
  3. 11:45—12:10
    回酒店取行李，前往机场
    优先约12:00左右离开酒店；从小什字可乘6号线换10号线到江北机场。
  4. 13:10—13:30
    目标抵达重庆江北机场
    留出值机安检缓冲，务必核对飞猪订单上的航站楼。
  5. 15:25—17:00
    重庆江北 → 武汉天河
    飞猪机票已订。
  6. 17:00—19:30
    机场入城 → 汉庭丁字桥路入住
    交通、晚饭时间根据同学见面安排调整。
  7. 晚上
    武大牌楼拍照，附近随意转转
    如果时间宽裕再考虑步行街；若指江汉路步行街，跨江较远，不强行当晚跑。
📍 现场提醒与备选

你之前说重庆只有一晚，朝天门已尽量放在前晚；12/1上午不再硬安排磁器口。

武汉第一晚以同学时间为准，不为“打卡步行街”横跨城市赶场。

12/02 周三武汉 · 同学带逛
主题：华中科技大学、湖北省博物馆、黄鹤楼夜景。此日由同学协调具体路线。
省博需预约黄鹤楼夜场需另查
  1. 09:30—12:00
    华中科技大学
    可以逛校园、见同学、一起吃饭，时间根据相约地点调整。
  2. 12:00—14:00
    午饭＋前往湖北省博物馆
    华科到省博相距不近，跨城交通要留至少45–70分钟弹性。
  3. 14:00—16:30
    湖北省博物馆
    优先曾侯乙编钟、越王勾践剑以及馆内其他重点展陈；预约时段以实际抢到为准。
  4. 17:30—晚上
    黄鹤楼夜景
    如只看外围亮灯外观，灵活安排；如进入《夜上黄鹤楼》，需要单独核实当天场次购票。
📍 现场提醒与备选

省博周三常规17:00闭馆、16:00停止入馆；黄鹤楼冬季日间常规开放至17:00，夜间进园是独立夜游安排。

省博若只约到上午，就与华科对调；如果当天见同学才是最重要的，优先保持朋友之间的弹性。

12/03 周四武汉 → 长沙
主题：下午抵达长沙后直奔橘子洲，晚上五一广场商圈夜游。
14:43到长沙南先放行李天黑前争取到橘子洲头
  1. 上午—11:35

  2. 11:35—12:25

  3. 13:17—14:43
    武汉站 → 长沙南站
    12306已订。
  4. 14:43—15:40

  5. 15:40—16:20

📍 现场提醒与备选

日落参考约17:30，橘子洲地铁站离南端雕像还有较长距离。若观光车候车很久，则不要为日落冒险赶路。

预约时段选择下午合适档位；景区预约和观光小火车购票是两件事。
